# Trip planner

Az osztály szavaz, hova menjen kirándulni. A szavazatok a votes.txt fájlban vannak, soronként egy helynév, kézzel beírva. Ezért lehet bennük felesleges szóköz és eltérő kis- és nagybetű, de a  Tata, a tata és a Tata ugyanazt a helyet jelenti. A program megszámolja, melyik hely hány szavazatot kapott, és kiírja a győztest a szavazatszámával együtt, például: Győztes: Balaton (2 szavazat). Az üres sorok nem számítanak szavazatnak.
